# 🛒 ShopEasy – Mini Shopping Website

ShopEasy is a mini E-commerce Shopping Website inspired by platforms like Amazon and Flipkart.  
This project was built using HTML, CSS, and JavaScript to simulate an online shopping experience.

---

## 🚀 Features

### 👤 Customer Features
- Browse products
- Add products to cart
- Remove products from cart
- View total cart price
- Responsive shopping interface

### 🛍️ Product Features
- Dynamic product cards
- Product images
- Product pricing
- Stylish UI design

### 💾 Storage Features
- Cart data stored using Local Storage
- Persistent cart even after page refresh

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage API
